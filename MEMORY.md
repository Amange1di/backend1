# EduOsh — Project Memory

## Контекст
EduOsh CRM — система управления образовательными центрами. Web: Next.js/React/TypeScript; API: Django REST Framework; mobile: Flutter. Поддержка кыргызского, русского и английского.

## Устойчивые решения
- Филиалы должны иметь отдельные данные и назначенного course_admin.
- Owner видит компанию и все филиалы в рамках разрешений.
- Backend является источником истины для прав и бизнес-правил.
- Повторно использовать существующие компоненты, особенно формы и UI.
- Не менять основной цвет на зеленый; умеренные скругления и качественная мобильная адаптация.
- Предпочтителен контролируемый релиз, без автоматического production deployment на каждый commit.

## Исторически обсуждавшиеся проблемы (требуют повторной проверки)
- Авторизация и первый вход, локализация, конфликты расписания.
- Доступность страниц и API, ошибки production migrations.
- UX библиотеки, домашних заданий, посещаемости и мобильных экранов.

## Правила памяти
Добавляй сюда только проверенные архитектурные решения, подтвержденные изменения и существенные ограничения с датой/ссылкой на коммит. Не хранить секреты, токены, пароли и персональные данные.
